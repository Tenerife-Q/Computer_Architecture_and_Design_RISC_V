# 第2关：第六章核心（★★）—— 磁盘调度算法

**【核心目标】** 扮演硬盘里面的那个“机械手臂”，用最短的移动距离，满足所有要求读取数据的任务。

### 0. 先理解场景（大白话）
你的电脑硬盘里有一张张像光盘一样的盘片，上面画满了一圈一圈的同心圆，这就是**“磁道”**（Track），编号比如从 0 到 199。
硬盘里有一个**“磁头”**（就像唱片机的唱针），要读取数据，磁头就得在这些磁道之间来回移动。**移动的距离越短，电脑运行越快。**

**【标准例题设定】**（我们用这一个例子打通所有算法）：
*   假设磁盘有 **0 ~ 199** 号磁道。
*   当前磁头正停在 **100号** 磁道。
*   并且磁头正在**向磁道号增大的方向（即向外，往199的方向）**移动。
*   现在有一堆任务排队等着读取，目标磁道号依次是：**`50, 120, 30, 190, 150`**。

---

### 1. FCFS 算法（先来先服务）—— 最傻但最公平
*   **规则：** 别人怎么排队的，你就按什么顺序去读。完全不管远近。
*   **路线：** 100（起点） → 50 → 120 → 30 → 190 → 150。
*   **计算移动距离（绝对值相减）：**
    *   100 到 50：移动了 50
    *   50 到 120：移动了 70
    *   120 到 30：移动了 90
    *   30 到 190：移动了 160
    *   190 到 150：移动了 40
    *   **总距离：** 50+70+90+160+40 = **410**。
    *   **平均寻道长度：** 410 ÷ 5（共5个任务）= **82**。
*   **评价：** 磁头就像个无头苍蝇东奔西跑，效率极低。

---

### 2. SSTF 算法（最短寻找时间优先）—— 贪心但短视
*   **规则：** 每次都挑**离当前位置最近**的那个磁道去读。
*   **路线推演：**
    1.  现在在 100。剩下的任务有 `[50, 120, 30, 190, 150]`。离100最近的是 **120**（距离20）。
    2.  现在在 120。剩下 `[50, 30, 190, 150]`。离120最近的是 **150**（距离30）。
    3.  现在在 150。剩下 `[50, 30, 190]`。离150最近的是 **190**（距离40，比去50近）。
    4.  现在在 190。剩下 `[50, 30]`。离190最近的是 **50**（距离140）。
    5.  现在在 50。只剩 **30** 了（距离20）。
*   **最终路线：** 100 → 120 → 150 → 190 → 50 → 30
*   **总距离：** 20+30+40+140+20 = **250**。 （比FCFS少多了！）
*   **缺点：** 容易产生**“饥饿”**现象。如果一直有100附近的磁道任务插队，那远处（比如30号）的任务可能永远等不到执行。

---

### 3. SCAN 算法（电梯算法）—— 最经典、考最多
*   **规则：** 就像坐电梯！电梯既然正在往上走，就**一路往上**，把路上的乘客都接完，直到**顶层（199号）**，然后再掉头**一路往下**。
*   **路线推演：**
    1.  起点是 100，方向是变大（往上走）。
    2.  往上的任务有：120, 150, 190。顺路接上。
    3.  **注意核心细节（考点）：** 接完190后，**必须走到头，也就是 199号！**
    4.  走到199号后，掉头往下。剩下的任务是 50 和 30。先路过50，再路过30。
*   **最终路线：** 100 → 120 → 150 → 190 → **199(掉头)** → 50 → 30。
*   **总距离巧妙算法：**
    *   往上走的总距离：199 - 100 = 99
    *   往下走的总距离：199 - 30 = 169
    *   **总距离：** 99 + 169 = **268**。
*   *(注：如果题目说的是LOOK算法，就不需要走到199，走到最远的190就直接掉头。但大纲写的是SCAN，考试时如果没特意说明，标准做法是碰到边界199才掉头)*。

---

### 4. C-SCAN 算法（循环扫描）—— 专治强迫症
*   **规则：** 这是一部“只接上楼乘客”的奇葩电梯。一路往上走到顶（199），然后**直接自由落体回到最底层（0）**，中途不接人，回到0之后再继续往上走。
*   **路线推演：**
    1.  起点 100，往上走：120 → 150 → 190 → **199**。
    2.  瞬间回到最底层：**0**。
    3.  再继续往上走，接剩下的任务：30 → 50。
*   **最终路线：** 100 → 120 → 150 → 190 → **199(跳跃)0** → 30 → 50。
*   **总距离：**
    *   第一段（100到199）：199 - 100 = 99
    *   第二段（199飞回0）：199 - 0 = 199 （部分考卷不计这段飞跃的寻道时间，但大部分期末考试要求算上绝对距离，按这个算最稳妥）。
    *   第三段（0到50）：50 - 0 = 50
    *   **总距离：** 99 + 199 + 50 = **348**。
*   **优点：** 确保了所有磁道被访问的时间非常平均，不会有人等太久。

### 📝 这一关的期末考点预测（大题拿分演练）

期末考试必然会出这样一道题，给你一个当前位置、一个方向、一串数字。让你写出：
**(1) 访问顺序**
**(2) 计算总寻道距离**
**(3) 计算平均寻道距离**

**你的小测验（你可以心里默想，或者在纸上画画，不用回复我具体数字，只要你能顺下来就行）：**
> 假设磁头在 **50号**，正在向 **编号小（减小）** 的方向移动。边界是 0~200。
> 任务队列：`[80, 20, 10, 120]`
> 你能在大脑里分别模拟出 **SSTF（最短寻找）** 和 **SCAN（电梯）** 的路线吗？
> *答案提示：*
> *SSTF：50 -> 20 -> 10 -> 80 -> 120*
> *SCAN（往下走）：50 -> 20 -> 10 -> 0(触底掉头) -> 80 -> 120*
