# 第5关：第七章重点（★）—— 外存分配方法与目录管理

**【核心目标】** 搞懂操作系统怎么把有限的硬盘空间，合理地分配给各种大小不一的文件。

### 0. 前置概念：磁盘块（Block）
硬盘不是一个可以无限延展的大面团，它被操作系统切成了一个个固定大小的小方块，叫**“磁盘块”**（比如一个块是4KB）。
你要存一个10KB的文件，系统就会给你分3个块（4+4+2）。

---

### 1. 外存分配方法 —— 【极高频考点】

系统给你分配这些“磁盘块”时，有三种经典的流派：

**① 连续分配 (Contiguous Allocation)**
*   **规则：** 就像去电影院包场，系统要求你的文件**必须存在连续相邻的磁盘块里**（比如占用第10、11、12号块）。
*   **优点：** 
    *   **极速读取：** 磁头“唰”地一下顺着读过去就行了，速度最快。
    *   支持**随机访问**：你想看文件的第3块，直接算一下物理地址（起点10 + 3 - 1 = 12号块），瞬间找到。
*   **缺点：**
    *   **产生外部碎片：** 磁盘用久了，到处都是零碎的小空地，大文件根本塞不进去。
    *   **文件难以扩展：** 如果你后面想给文件追加内容，发现它后面的位置被别的文件占了，你就得把整个文件搬家，非常崩溃。

**② 隐式链接分配 (Implicit Linked Allocation)**
*   **规则：** 就像**寻宝游戏**。系统随便给你找几个空闲块（不要求连续）。每个块里面，除了存你的文件数据，还偷偷藏了一张**“纸条”（指针）**，写着“下一个块在XX号”。
*   **优点：**
    *   **绝无外部碎片：** 硬盘上只要有空块就能用。
    *   **扩展极方便：** 想加内容？随便找个空块写进去，然后把前一个块的指针指过来就行。
*   **缺点：**
    *   **只能顺序访问（致命伤）：** 如果你想看第100个块的内容，你必须从第1个块开始，顺着线索一个一个找，找死你。
    *   **指针占空间，且不可靠：** 万一中间某个块坏了，后面的线索全断了，文件直接报废。

**③ 显式链接分配 (Explicit Linked Allocation / ★ FAT表)**
*   **规则：** 这是隐式链接的**超级进化版**。系统觉得让磁头在硬盘上飞来飞去找线索太慢了。于是，系统把所有块里面的“小纸条”（指针）全部抽出来，集中放在一张大表格里，这张表格就叫 **FAT（File Allocation Table，文件分配表）**！
*   **工作机制：** 这张 FAT 表是在开机时就被**调入内存**的。当你要找文件的第100个块时，系统直接在内存里查FAT表，顺藤摸瓜瞬间算出物理地址，然后再去读硬盘。
*   **优点：** 
    *   支持了**快速的随机访问**（因为查表是在内存里进行的，速度极快）。
    *   没有外部碎片，扩展也方便。
*   **缺点：** FAT表需要一直常驻内存，会占用宝贵的内存空间。

### 2. 目录管理 (大纲要求：简单了解)

你平时建的“文件夹”，在操作系统里就叫**“目录”**。

*   **FCB（文件控制块）：** 这是目录管理的核心概念。一个文件在系统中有一个**“身份证”**，这就叫FCB。里面记录了文件名、文件在硬盘的哪个位置（物理地址）、大小、权限等。**一个目录（文件夹）里面，其实存的就是一堆FCB。**
*   **树形目录结构：** 这是现代操作系统（Windows、Linux等）都在用的。有一个根目录（比如Linux的 `/` 或者 Windows的 `C:\`），下面有子目录，子目录下面还有子目录，像一棵倒过来的树。
    *   *优点：* 解决了不同用户给文件起名字冲突的问题（只要不在同一个文件夹下，同名完全没问题）。
    *   *常考名词：* 
        *   **绝对路径：** 从根目录开始一路写下来的路径（如 `C:\Users\Desktop\A.txt`）。
        *   **相对路径：** 从当前你所在的文件夹开始写的路径。

4. 文件目录的基本存储单位（也就是文件的“身份证”）叫什么？（答：FCB / 文件控制块）

1. **简述连续分配和链接分配的区别。**
